# 🔫 MCWeapon - 现代战术枪械模组 (Tactical Weapons Arsenal)

![Minecraft](https://img.shields.io/badge/Minecraft-26.3-brightgreen?style=for-the-badge&logo=minecraft)
![Fabric](https://img.shields.io/badge/Mod_Loader-Fabric_0.19.5+-dbd0b4?style=for-the-badge)
![Java](https://img.shields.io/badge/Java-25+-orange?style=for-the-badge&logo=openjdk)
![License](https://img.shields.io/badge/License-MIT-blue?style=for-the-badge)

**MCWeapon** 是一款专为 **Minecraft 26.3 (Fabric)** 设计的现代战术枪械模组。模组内置 **13 款经典热门枪械型号**（涵盖狙击步枪、冲锋枪、手枪、突击步枪与战术霰弹枪）及 **战术高爆弹药箱**。每款枪械均具备独立的射速、单发伤害、爆头倍率、弹匣容量、穿透属性、专属定制合成音效以及 32×32 高清像素贴图。

全系枪械标配 **实时激光瞄准红点 (Laser Sight Red Dot)** 与 **光学变焦开镜放大 (Optical Scope Zoom)**，并采用**安全射线弹道机制**：**仅对实体生物 (`LivingEntity`) 产生伤害，对世界方块及装饰实体（画、物品展示框、盔甲架等）零破坏**。

---

## ✨ 核心特性

- 🎯 **13 款热门枪械型号**：覆盖 **AWP**、**巴雷特 M82A1**、**Kar98k**、**KRISS Vector 短剑**、**MP5A5**、**FN P90**、**Micro UZI**、**沙漠之鹰**、**Glock-18C**、**USP-S**、**AK-47**、**M4A1-S**、**SPAS-12**。
- 🔴 **实时激光瞄准红点**：主/副手持有枪械时，自动投射战术激光束并在落点生成高亮度红点（支持 100+ 格超远距离渲染）；瞄准生物时底部 HUD 实时显示**目标名称、剩余生命值、激光测距与爆头点提示**。
- 🔍 **光学变焦开镜放大**：支持 **按住 Shift 键快速开镜** 或 **左键锁定开镜**。基于客户端 `PlayerScopeMixin` 与服务端动态属性同步，开镜时提供高清望远镜级光学放大、平滑鼠标降敏，并大幅收束子弹散布。
- 🛡️ **零方块破坏安全弹道**：
  - 子弹仅对活体生物 (`LivingEntity` 且排除 `ArmorStand` 盔甲架) 造成伤害；
  - 绝不破坏任何世界方块（包括玻璃、树叶、花盆、火把等）；
  - 手持枪械时拦截左键挖掘（即使在创造模式下左键点击方块也不会破坏方块）。
- ⚡ **真实无敌帧穿透**：针对高射速冲锋枪（最高 20 发/秒）与多弹丸霰弹枪，命中时自动重置目标受击无敌帧 (`invulnerableTime = 0`)，确保每一发子弹与每一颗弹丸的伤害 100% 生效。
- 🔊 **程序化合成枪声 + 高清像素贴图**：内置构建脚本通过音频合成算法与 `ffmpeg` 自动生成 9 种枪械专属 `.ogg` 音效，并通过 `Pillow` 绘制全套 32×32 像素贴图与第一/第三人称双手持枪姿态。

## 🎮 操作指南与游戏内用法

### 1. 基础操作按键

| 动作 | 操作方式 | 说明 |
| :--- | :--- | :--- |
| **开火射击** | **按住鼠标右键 / 点击右键** | 冲锋枪、步枪、Glock-18C 支持**按住右键全自动连发**；狙击枪、霰弹枪、半自动手枪按各自射速间隔射击。开火时不会降低角色移动速度。 |
| **快速战术开镜** | **按住 `Shift` (潜行键)** | 按住 `Shift` 立即进入光学放大视野与高精度低散布模式；松开 `Shift` 立即恢复正常视野。 |
| **锁定/切换开镜** | **手持枪械左键点击方块** 或输入 `/weapon scope` | 切换枪械的持续开镜状态（可在正常行走/移动中保持开镜放大）。 |
| **手动换弹** | **按 `F` 键 (副手切换键)** / **Shift+左键点击方块** / `/weapon reload` | 弹匣打空时会自动触发换弹；弹匣未满时按 `F` 键即可立即手动换弹（枪械会自动保留在主手）。 |
| **激光瞄准测距** | **主手或副手持有枪械** | 自动激活红色激光束与落点红点，底部状态栏实时显示弹匣余量、激光测距与锁定目标血量。 |

### 2. 游戏内快捷指令 (`/weapon`)

模组内置 `/weapon` 指令，所有玩家均可使用：

```mcfunction
# 查看武器库帮助说明与型号列表
/weapon

# 一键向背包发放全套 13 把热门枪械 + 战术高爆弹药箱
/weapon all

# 领取指定型号的枪械（支持自动补全名称）
/weapon give awp
/weapon give barrett_m82
/weapon give kriss_vector
/weapon give desert_eagle

# 切换当前手持枪械的光学倍镜开关
/weapon scope

# 为当前手持枪械手动换弹
/weapon reload
```

> 💡 **创造模式物品栏**：在创造模式物品栏中可直接打开独立的 **“现代战术枪械库 (MCWeapon)”** 标签页或原版 **“战斗用品”** 标签页获取所有武器。

## 🔧 编译与部署指南

### 环境依赖
- **Minecraft 版本**: `26.3` (Unobfuscated)
- **Mod Loader**: `Fabric Loader >= 0.19.5` + `Fabric API >= 0.161.0+26.3`
- **JDK**: `Java 25+`
- **Python 依赖**（仅构建脚本使用）: `Python 3.10+`、`Pillow` (`PIL`)、系统已安装 `ffmpeg`

### 一键构建 (`make_mod.py`)

本项目提供零 Gradle 依赖的极速构建脚本 `make_mod.py`，直接利用服务端运行环境的 `server-26.3.jar` 与 `libraries` 进行编译打包：

```bash
# 1. 运行构建脚本（自动生成音效、贴图、模型、配方并编译打包 JAR）
python3 make_mod.py

# 2. 构建产物路径
ls -lh /tmp/mcweapon-1.0.0.jar
```

### 部署到服务器

```bash
# 将构建好的模组复制到服务端 mods 目录并重启服务
cp /tmp/mcweapon-1.0.0.jar /opt/minecraft/mods/mcweapon-1.0.0.jar
chown minecraft:minecraft /opt/minecraft/mods/mcweapon-1.0.0.jar
systemctl restart minecraft
```

- 如果服务器安装了 **AutoModpack**，服务端重启后会自动将 `mcweapon-1.0.0.jar` 同步至客户端；
- 也可以直接将 `build/libs/mcweapon-1.0.0.jar` 放入本地客户端的 `.minecraft/mods/` 目录中使用。
